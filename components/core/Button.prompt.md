Pill-shaped call-to-action button in five variants, used for every clickable action in the ProFily system.

```jsx
<Button variant="primary" size="md" onClick={submit}>Enviar declaração</Button>
<Button variant="secondary">Cancelar</Button>
```

Variants: `primary` (sky blue, main CTA), `dark` (navy, high-contrast on light backgrounds), `secondary` (outlined), `ghost` (text-only), `danger` (destructive actions). Sizes: `sm`, `md`, `lg`. Pass `icon` for a leading icon node.
